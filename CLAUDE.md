# AIPDFBuilder

Sciter.js Windows desktop app — a blank, self-contained native sandbox (no external SDK checkout required to build).

## Architecture

- Native host (`src/main.cpp`, C++17) creates a `sciter::window` and loads the UI. Release loads packed resources (`this://app/main.htm`, generated into `src/resources.cpp` by `packfolder.exe` at pre-build); Debug resolves `res/main.htm` on disk instead, so edits show up on relaunch without repacking.
- Sciter.js frontend lives under `res/` — `main.htm` is the window shell, `shared/lib/router.js` is a slot-based router utility (not wired up yet), `shared/lib/tokens.css` holds design tokens. Currently just a placeholder body — no real pages/components exist yet.
- Flat single-stack project — one native host + one resource tree, no sub-modules or workspace split.
- Environment + project-readiness calibration (GP-460/467: fonts, Sciter version/quirks, render pipeline, per-project font-substitution policy — status OK/stale, checked by `calibrate-check` before create-component/create-page Step 0): [.claude/state/calibration.json](.claude/state/calibration.json)

## Build & Run

- Prerequisite: Visual Studio 2022+ with "Desktop development with C++" (`v143` toolset).
- Build: `build.bat [Debug|Release]` (wraps MSBuild on `AIPDFBuilder.sln`, x64)
- Run: `run.bat [Debug|Release]`
- Fast iteration without compiling: `tools\run-scapp.bat` (needs a separate `sciter-js-sdk` checkout with `scapp.exe`; point `SCITER_SDK_ROOT` at it)
- Pre-build packs `res/` into `src/resources.cpp` via `packfolder.exe`; post-build copies `sciter.dll` next to the exe.
- Build against a different SDK by setting the `SCITER_SDK_ROOT` env var (defaults to the vendored `third_party/sciter-sdk`).

## Project Structure

    src/main.cpp            — native host: MainWindow (sciter::window), resource loading, dev-vs-packed URL resolution
    src/resources.cpp       — generated by packfolder.exe pre-build (gitignored)
    res/                    — Sciter JS/CSS/HTML content, served as this://app/... at runtime
      main.htm              — window shell (placeholder body)
      shared/lib/router.js  — slot-based router utility (not wired up yet)
      shared/lib/tokens.css — design tokens (colors, spacing, radius)
    win-res/dpi-aware.manifest — DPI-awareness manifest, linked into the exe
    third_party/sciter-sdk/    — vendored Sciter SDK (headers, packfolder.exe, sciter.dll) for a self-contained build
    tools/run-scapp.bat        — scapp.exe-based fast-iteration alternative (needs external SDK checkout)
    builds/<Config>/           — build output (gitignored)

## Code Conventions

- C++17, MSVC `v143`, no precompiled header (`PrecompiledHeader: NotUsing`)
- No `.clang-format` / `.editorconfig` yet — match surrounding style (Sciter SOM passport pattern in C++, 2-space indent in JS/JSON)
- JS: JSDoc typedefs for types (`checkJs: true` in `jsconfig.json`), ES modules, JSX enabled (`jsx: react`) for Sciter's JSX support
- Sciter script runtime features are explicitly allowlisted via `SciterSetOption` in `uimain` (file/socket IO, eval, sysinfo) — keep that allowlist minimal
